# Farid Rahman Portfolio

A production-ready personal portfolio for Farid Rahman, built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Embla Carousel, Radix primitives, React Hook Form, Zod, and optional Resend email delivery.

## Prerequisites

- Node.js 20.9 or newer
- npm 10 or newer

## Installation

```bash
npm install
```

## Local Development

```bash
npm run dev
```

Open `http://localhost:3000`.

## Environment Variables

Copy `.env.example` to `.env.local` and fill in values as needed.

```bash
RESEND_API_KEY=
CONTACT_TO_EMAIL=
CONTACT_FROM_EMAIL=
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

The contact form validates on the client and server. In development, if email variables are missing, the API returns a clear development-mode response and logs only non-sensitive metadata. In production, missing email configuration returns an explicit error.

The included in-memory rate limit is suitable only for a demo or single-process deployment. Use Redis, Upstash, a database, or another distributed store for multi-instance production.

## Build

```bash
npm run lint
npm run build
npm run start
```

## Deploy to Vercel

1. Push the project to a Git repository.
2. Import the repository in Vercel.
3. Add the environment variables from `.env.example`.
4. Deploy with the default Next.js settings.

## Deploy to a VPS with Node.js and Nginx

1. Install Node.js 20+, npm, and Nginx on the server.
2. Clone the repository and install dependencies.
3. Add `.env.production` with the required contact variables.
4. Build and run the app:

```bash
npm install
npm run build
npm run start
```

5. Use a process manager such as `pm2` or a systemd service to keep the app running.
6. Configure Nginx as a reverse proxy to the Next.js port, usually `3000`.
7. Add TLS with Certbot or your certificate provider.

## Editing Content

Portfolio content lives in `data/portfolio.ts`, including identity, navigation, social links, hero copy, projects, metrics, affiliations, technologies, services, and contact text.

Replace local artwork in:

- `public/projects/`
- `public/profile/`
- `public/branding/`
- `public/og/`

## Generated Output

`.next/` and `/_next/` are generated by Next.js. Do not edit, upload, or commit them as source files. Run `next dev` or `next build` to regenerate build output.
